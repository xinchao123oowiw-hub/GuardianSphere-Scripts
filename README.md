## 🎮 Cách sử dụng

1. Copy toàn bộ code từ `guardian_ultimate_ragdoll.lua`
2. Dán vào Console/Script Executor (Synapse X, Script-Ware, v.v...)
3. Bấm Execute
4. Bấm phím **G** để bật/tắt
